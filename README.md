💸 Nirmala Budget Tracker - Console-Based Python Project 💻
"A simple yet powerful tool to track your income and expenses."

👋 Hi there!
This project is called Nirmala Budget Tracker, a console-based Python application designed to help users manage their personal finances effortlessly.

📊 With this tracker, you can:

✅ Add and monitor income

❌ Record expenses

🔍 Search transactions by date, category, amount, and more

💾 Save & load your data using CSV files

💰 View your current balance in real-time

🧠 The main purpose of this project is to recap and apply all key concepts of Python, including:

Classes & Objects 🧱

File Handling 📁

Data Structures 🧮

Exception Handling ⚠️

External Libraries like pandas 📊

✨ Hope it helps others who are learning Python too!
Feel free to explore, learn, and build on top of it. Happy Coding! 🚀
